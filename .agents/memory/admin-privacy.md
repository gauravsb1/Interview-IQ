name: Owner-only analytics dashboard
description: Persistent access boundary for InterviewIQ candidate analytics and records.
---

InterviewIQ's candidate analytics and private records are for the owner only and must use a separate admin sign-in, not candidate accounts.

**Why:** the user asked for a separate dashboard that only they can access.

**How to apply:** protect every admin API server-side; do not rely on hiding routes or matching an email address alone.
