---
name: InterviewIQ friend requests
description: The chosen approval rule for adding friends in InterviewIQ chat.
---

Friend connections require an explicit request and recipient acceptance; sending a request alone does not create a friendship.

**Why:** The user chose “Request and accept” rather than instant connections.

**How to apply:** Keep friend-request states separate from existing direct-message access, and do not mark a user as a friend until the recipient accepts.
